## What this run did not cover

The list of [v0.3.0](v0.3.0.md#what-this-run-did-not-cover) still holds. For this release in particular:

- the AI functions were tested in CI with a fake OpenAI-compatible provider; against a real provider (OpenRouter) only images, a snippet and the text of an element
  were tried, on a development machine; the website wizard and the page translation were not;
- the migration 0073 was run by the `upgrade` workflow on the test data and on a development database, not yet on the reference host;
- arm64 was built only by the release workflow; no published arm64 image was scanned for this release.
