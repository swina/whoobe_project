## What this run did not cover

As stated in the status summary, section 3, and not repeated as a claim of safety:

- no external audit, penetration test or certification: all the work is ours;
- the **manual security checklist was not repeated** for the features added since 0.2.0 (Generate Website Wizard and site specification, Kits, uploaded fonts, `private` profile, fleet commands), and the browser suite was not extended for them;
- the Assets changes of 2026-10-23 (type filter, audio, PDF preview with the session) were not checked in a browser;
- the AI provider path of the Generate Website Wizard was never exercised;
- SQL fuzzing of the remaining endpoints, the impact of prompt injection on the AI features, a `next build` or `nuxt build` of generated sites, load testing (by design);
- a full Content-Security-Policy for the admin and editor SPAs (postponed on purpose, F-014);
- TLS on a real hostname with a public certificate;
- the browser-side XSS coverage of some `v-html` sinks (F-008);
- Microsoft Entra, Okta and Google single sign-on, and a real Cloudflare Images account.
