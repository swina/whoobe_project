# AI

Whoobe uses AI to help authors, and it **does not ship or resell any AI**. You connect the provider you choose with your own key; nothing is sent
anywhere until a person uses an AI function. This section describes what the AI functions do, how they are configured and what they cost in
terms of data and control.

| Document | What it covers |
|---|---|
| [AI features](ai-features.md) | Generating pages, snippets and text, generating images, translating, the website wizard, Figma import; providers, configuration, permissions, limits, data protection, what AI does not do |
| [Data protection](../security/data-protection.md) | Which content reaches an AI provider (section 4) |
| [Secrets and keys](../operations/secrets-and-keys.md) | How AI provider keys are stored |
| [Sandbox](../operations/sandbox.md) | The public demo profile switches AI off |

**In the dashboard:** the **AI** entry of the sidebar has three cards (*AI Agent*, *AI Image Generation*, *AI Translation*); *Settings > Figma* holds the
Figma token. The functions themselves are in the editor (generate a page or snippet, generate an image, translate) and in the dashboard
(the *AI Website Wizard* in the website settings, *Generate with AI* in Assets).
