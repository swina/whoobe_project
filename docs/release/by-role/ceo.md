# For the CEO, owner or sponsor

## What you are deciding
Whether to **own your web and integration platform** (self-hosted, MIT, no per-user or per-call fees) in return for **running it yourselves**
(or paying someone to). It is a good bet if you want control of data, credentials and infrastructure and have, or can buy, the people to run
it. It is a poor bet if you need a vendor SLA, certificates or single sign-on today.
