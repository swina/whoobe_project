# Website

In whoobe_cms the website object has not been defined yet.

As a CMS the concept of website can be assume different structure:

- single website multilanguage
- multiple website multilanguage

## Website Services

In order to serve a website whoobe_cms can take different directions:

- create headless website services (API)
- integrate a webserver (nginx) and serve static pages
- use a SSR system adopting a internal routing system
- more options?

## Open architecture

The main goal as a open-source solution is to leave to the user the decision which type of website wants to serve using whoobe cms
