# Data Objects : views, editing UI

This document summarize the UI requirements for managing data objects:

- list view, with pagination (custom rows x page)
- advanced filter on field
- edit record doesn't open a modal but a new tab (like images) and a new content with the record CRUD
- for Pimcore import multilanguage data records that have the same order (Pimcore ID?) are ipotetically the same record, in this case the CRUD page should manage the editing by creating a sub tab system for each language and the associated data
- data export: csv, xlsx, json
